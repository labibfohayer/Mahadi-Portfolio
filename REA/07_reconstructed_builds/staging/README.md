# REA Staging Area
This directory holds newly reconstructed React / Next.js components generated during Phase 06.

### Rules of Staging:
1. Reconstructed files land here first (e.g. `HeroCanvasScene.tsx`).
2. Run `npx tsc --noEmit` and browser inspection to confirm zero errors.
3. Complete the `qa-verification-checklist.md` gate.
4. Only upon approval, copy or move the verified component into `src/components/`.
